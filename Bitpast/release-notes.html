Version 4.7

November 12, 2026

Three new machines bring BitPast to 18 systems, and opening pictures is quicker.

NEW MACHINES
  • ColecoVision: 256x192 pictures in 15 colors, saved as a 16 KB cartridge (.col) that shows your picture as soon as the console starts
  • Commodore PET: 40 or 80 columns of block graphics in green or white, saved as a program (.prg) for the PET 2001, 3000, 4000 or 8032 - and they go on D64 disks
  • Atari 2600: 40x192 playfield pictures with two of 128 colors on every line, saved as a 4 KB cartridge (.bin)
NEW
  • An Open Images button in the empty image browser, and File > Open Images (Cmd-O)
  • File > Open Recent lists the last 10 pictures you opened
  • The system bar fits any window size and scrolls when there isn't room for every machine
  • A free 91-page User's Guide (PDF) covering every system, mode and setting
CHANGED
  • Create Disk is dimmed for the consoles, whose pictures are cartridges
FIXED
  • Plus/4: red and blue were swapped
  • MSX Screen 2 files (.sc2) now load correctly with BLOAD
version_4_6.txt

Version 4.6

November 5, 2026

Choose how a photo fills the screen, and better palettes on the Apple IIgs.

NEW
  • Fit for every machine: Stretch, Contain (black bars), Cover (crop) or None (no scaling)
  • Aspect: takes each machine's non-square pixels into account, so circles stay round
  • Drag the preview to choose which part of the picture shows
  • Apple IIgs 256 colors: new SCB Mode - Per-Line lets every line pick the best of the 16 palettes
FIXED
  • Palette editor changes are now saved in the file, in batch exports and on disk images
  • H-Flip and V-Flip now flip the saved file and disk images too, not just the preview
  • Apple II and IIgs results no longer depend on the screens attached to your Mac
version_4_5.txt

Version 4.5

October 25, 2026

Better colors, disk images that load on real machines, and an app that stays responsive while it works.

NEW
  • ZX Spectrum +3 disk images (180 KB .dsk)
  • Double-sided 360 KB TRS-80 CoCo disks, and DOS 2.5 support for 130 KB Atari disks
  • A Converting... indicator over the preview while a new picture is calculated
CHANGED
  • Smarter color selection for the Atari 800, Atari ST, Amiga 500 and 1200, PC (EGA 64) and MSX Screen 5: small details keep their own color instead of turning grey
  • Atari 800 Graphics 8 uses two shades of one hue, exactly like the real hardware
  • Conversions run in the background, so the window stays responsive
  • Much faster PC 256-color and Amiga 1200 conversions
FIXED
  • C64 PETSCII programs now run on a real C64
  • BBC Micro, TRS-80 CoCo, Amiga ADF, Atari ATR and ZX Spectrum TRD disks are now read correctly by the real machines and emulators
  • Amstrad CPC files use the correct colors on a real CPC
  • Locked settings are now used by the Atari 800, Atari ST and BBC Micro in batch exports
  • The same picture with the same settings always converts the same way
  • Saving over an existing file keeps the original if the save fails
version_4_3.txt

Version 4.3

February 26, 2026

Reliability: clearer errors and safer disk images.

FIXED
  • Failed saves and batch exports now tell you which files could not be written
  • Rapid slider changes no longer flash an outdated preview
  • The disk progress bar now reaches 100%
  • Disk images report files that don't fit instead of writing damaged ones
  • Amiga disks: large files (over about 35 KB) and files with similar names are no longer lost
  • Plus/4 now uses Shift-Cmd-L, which no longer clashes with the Amiga 1200
  • Amiga 1200 320x512 pictures have the correct proportions
  • Several rare crashes with unusual pictures

version_4_0.txt

Version 4.0

January 31, 2026

Disk images for every system.

NEW
  • Create Disk for every system: D64/D71/D81, ADF, ATR, ST, SSD/DSD, MSX and CPC DSK, TRD, PC IMG and ProDOS
  • A new Create Disk sheet with all systems, formats, sizes and volume-name checks
  • A progress bar while disks are created
  • Atari ST medium (640x200) and high (640x400) resolution
FIXED
  • VIC-20 Hi-Res: no more stray dots in flat areas
  • Commodore disks: correct file names and much better use of disk space
  • Disks now contain every selected picture, not just one
  • Amiga disks with several pictures, long Amstrad CPC files and Atari ST high resolution no longer fail
  • Apple IIgs 3200-color pictures on ProDOS disks are recognised by other viewers
