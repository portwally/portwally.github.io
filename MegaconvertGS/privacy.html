Privacy Policy

MegaconvertGS does not collect anything.

The program. MegaconvertGS runs on an Apple IIgs (or an emulator) and has no network features at all. Pictures you load, convert and save stay on your disks. Its preferences are kept in the file MCGS.Prefs beside it.

This website. The site is hosted on GitHub Pages. It uses no cookies and no tracking. GitHub, as the host, may record technical data such as your IP address in its server logs; see the GitHub privacy statement for details. The download link leads to GitHub.

Children. The program is suitable for all ages and collects no data from anyone.

Changes. If this policy changes, the new version will be published on this page. Last updated: October 2026.
