Next version

In development

New

  • Quick Look in the Finder — Press Space on a disk image (.po, .2mg, .hdv, .dsk, .do, .woz) or a ShrinkIt or Binary II archive in the Finder to see its volume, format, size and every file with type, aux type, size and date.
  • Finder icons — Disk images show as a 5.25″ or 3.5″ floppy or a hard disk, archives as a box, labelled with the volume name.
  • Drop into folders — Drop files on a folder to copy them into it, or on a file inside an open folder to copy them next to it. The folder lights up while you drag.
  • Open Recent — File › Open Recent lists the last ten pairs of disks you had open; pick one to open both again, each in its own pane.
  • Folders from the keyboard — Return opens or closes the highlighted folder; the right and left arrows open and close it.

Fixed

  • The main window no longer jumps up when the inspector opens.
  • The disk's file name stays in view in narrow panes, and the window can no longer be made narrower than its toolbar.

Version 1.9

7 November 2026

New

  • Sortable columns — Click Name, Type, Size or Modified to sort the file list; click again to reverse it, a third time for the order on the disk. Open folders, the arrow keys and Shift-click follow the order shown, and dates sort as dates.

Version 1.8

5 November 2026

New

  • Preview pane — The Preview button turns a pane into a live preview of the file selected in the other pane: its content, every directory field, IIgs resource forks and a hex dump.
  • Edit in the preview — Change a file's type and aux type; edit and save a MOD file's song title and sample names.
  • WOZ disk images — Read-only. 5.25″ and 3.5″ bit images are decoded natively; copy-protected disks open as far as they can be read; title, publisher and other details in Disk Image Info.
  • .img disk images — Raw images read and write; DiskCopy 4.2 read-only.
  • Sound and music — IIgs sampled sounds, rSound resources, HyperStudio, ASIF, AIFF, SoundSmith, NinjaTracker Plus, MOD and MIDI play when opened.
  • Skins — System, Light, Dark, Norton Commander and Apple IIGS 640 (RetroBrowse › Settings).
  • Welcome on first launch, with the backup warning; again from the Help menu.
  • Archives dropped on an open disk — Choose to copy it as a file, unpack its files, or open it.
  • Browse ShrinkIt and Binary II archives that hold files rather than a disk, as a read-only catalog.
  • Keyboard — The arrow keys move through a pane and the inspector follows; Space opens and closes the inspector; Delete deletes after asking; ⌘O and ⇧⌘O open a disk in the left or right pane.
  • Expand / Collapse All buttons in each pane.
  • Help — A table of every file and aux type with what RetroBrowse can show; a Sound & Music topic.
  • Pictures fit the inspector and preview by default (Fit, 1x, 2x, 3x).
  • Errors are shown — Failed imports, copies, deletes and loads say what went wrong. Several files can be dropped from the Finder at once.
  • More previews — PaintWorks animations, packed 3200-color pictures, Apple's packed Hi-Res and Double Hi-Res files, and 65C02 instructions in the disassembler.

Changed

  • Files exported or dragged to the Finder get their file type as extension (PRODOS.sys, FONT.fon).
  • A disk changed from the preview or by a copy keeps the same files selected after it reloads.
  • The Super Hi-Res decoders are now the ones from Retro Graphics Converter, so both apps show the same pictures.
  • The disk writers never use a block or sector that a file already uses, even if the disk's own free map says it is free. Full subdirectories grow.

Fixed

  • DOS 3.3 writing could overwrite existing data, because the free-sector map was read with its bytes swapped.
  • DOS-ordered ProDOS images (.dsk, .do) read and wrote one block per track from the wrong sector.
  • Disk images dropped from the Finder are opened in place even when another app claims their type; before, changes could go to a temporary copy and be lost.
  • Files with the same name in different folders — Delete, rename and change type act on the selected file.
  • Cut and paste only removes a file from the source after it was copied; deleting a folder deletes its contents and frees their blocks.
  • ShrinkIt, Binary II and ZIP archives open correctly, including ZIP files made by the Finder.
  • Rows dragged to the Finder arrive as files instead of a text clipping.
  • Dates from 2000 to 2039 and hour/minute order; new .2mg images get a proper 2IMG header.
  • Viewers — 640-mode and DreamGrafix pictures, large Apple Preferred Format pictures, Finder icon colors, AppleWorks GS documents read in full, Merlin columns, DOS 3.3 BASIC and binary files, AppleWorks characters and Teach styles.
  • Crashes in the 65816 disassembler, with large DOS 3.3 files, dates from 2028 on, and several damaged files.

Earlier development

Before version 1.8, development builds used their own numbers; they are listed here by date.

January 2026

  • File Inspector with Content, Hex and Info tabs (⌘I or right-click).
  • Viewers — Applesoft and Integer BASIC listings with syntax colors, Merlin assembler source, a 6502 disassembler, Hi-Res, Double Hi-Res and Super Hi-Res pictures, IIgs and Hi-Res fonts, IIgs icons, AppleWorks (word processor, database, spreadsheet, GS), Teach documents, and a hex dump.
  • Files with resource forks are read, so Teach and other IIgs documents open.
  • Disk image verification and a detailed File Info panel.
  • Change file type and aux type by right-clicking a file.
  • Built-in Help with shortcuts, formats and troubleshooting.
  • ShrinkIt archives and UCSD Pascal volumes (read-only).
  • Long BASIC and Merlin lines wrap neatly; files dropped from the Finder keep their names.
  • No external tools needed: everything is done natively in Swift.

2024 – 2025

  • The first versions — Dual-pane browser, drag and drop between disk images, ProDOS and DOS 3.3 reading and writing, copy, cut, paste and delete, folders, 200+ file types, dates, graphics preview and export to the Finder.
